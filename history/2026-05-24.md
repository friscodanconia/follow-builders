Solo founders are quietly becoming one-person armies with AI agents. Meanwhile, the infrastructure to support them is maturing faster than anyone expected.

**Y Combinator's Garry Tan ships voice agents for everyone**
Tan released GBrain v0.40.0, which adds voice capabilities to AI agents using Google's Gemini Live. The open-source tool gives agents large context windows, tool access, and what Tan calls "full brain access." He's positioning it as having two personalities: Mars as a friend and Venus as an executive assistant.
Why it matters: When YC's president is shipping open-source agent tools, he's signaling where he thinks the market is headed. Expect the next batch of YC companies to have voice agents built in from day one.

**GitHub adds native pull request limits**
Developer Peter Steinberger noted that GitHub now natively supports limiting pull requests per person, a feature his team previously had to build with custom bots. The change suggests GitHub is responding to teams that need better workflow controls as development gets faster.
Why it matters: When GitHub builds features that developers were hacking together with bots, it usually means that workflow is becoming standard practice. PR limits are about to be table stakes for any serious development team.
