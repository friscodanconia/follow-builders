**AI Builders Digest — November 11, 2026**

Two stories today sit at opposite ends of the AI security spectrum. Google just proved that AI can verify three million lines of encryption code without a single human reviewing each proof. And Microsoft just showed that the same AI agents doing that verification could be silently compromised by flipping fewer than ten neurons. Progress and peril, shipping on the same day.

---

**Google DeepMind's AI verified Signal's encryption, all three million lines of it**

AlphaProof Code, DeepMind's formal verification system, wrote and checked three million lines of mathematical proof in Lean to verify the core encryption code that protects Signal messages. This is not testing. It is a machine-checked mathematical guarantee that the code does what it claims. No human could read three million proof lines in a career, let alone a sprint.

Why it matters: Signal's encryption protects journalists, dissidents, and roughly everyone who has ever read a "use Signal" recommendation. If AlphaProof Code's approach scales to other critical software, the era of "we think this crypto implementation is correct" ends and the era of "we know" begins. That is a different world for anyone responsible for security audits.

https://deepmind.google/blog/introducing-alphaproof-code/

**Microsoft found a backdoor that hides in dormant neurons and waits**

Microsoft researchers discovered a technique they named Lazarus: an attacker can reprogram fewer than ten dormant neurons in an AI model to install a hidden backdoor, with no retraining required. The compromised model behaves completely normally until a specific trigger appears, such as the clock ticking past midnight into 2027, at which point it can quietly download and execute attacker code, steal secrets, or run destructive commands. It passes standard safety evaluations. You would not catch it.

Why it matters: Every company deploying open-weight models right now is exposed to this. The attack requires no access to your infrastructure after the model is loaded. If you pulled a model from a public repository and put it inside a product with terminal or API access, Lazarus describes a plausible path for that model to become a time-delayed intrusion. Microsoft is building cryptographic signing and AI-powered weight scanning as defenses, but those are not shipping today.

https://www.microsoft.com/en-us/research/blog/lazare-veni-foras-reprogramming-dormant-neurons-to-backdoor-ai-agents/

**Vercel's Guillermo Rauch thinks MCP could be bigger than AI**

Vercel CEO Guillermo Rauch posted that MCP (the Model Context Protocol, a standard for letting AI agents communicate with external tools and services) could matter even without AI, calling it a potential "civilization-scale accomplishment" to get all software systems talking through one universal open protocol. His specific addition: MCP Events, which lets agents subscribe to notifications instead of repeatedly checking for updates. An agent that deploys code can now wait to be told the deployment finished rather than constantly asking.

Why it matters: The polling-versus-events distinction is small but compounds fast. Agents that constantly check for status updates burn compute and slow down. Agents that wait for a callback can run in parallel across dozens of tasks without stepping on each other. If MCP Events becomes a standard, the architecture of multi-agent systems gets meaningfully cleaner, and Vercel's deployment platform sits right in the middle of that workflow.
