**Cursor's exit rewrites what a developer tool company is worth**

Box CEO Aaron Levie posted a thread this weekend making the case that Cursor executed the applied AI strategy better than anyone predicted. His core point: the biggest developer tool exits in history topped out in the low billions, the market was already considered crowded when Cursor launched, and almost nobody modeled for how large agentic coding would actually become. Multiple assumptions shattered at once.

Why it matters: Every VC partnership that passed on AI coding tools in 2023 because "the market is too small and GitHub Copilot will just win" is having a very bad Sunday. More practically, if agentic coding can create this kind of outcome in a space everyone called saturated, the same logic applies to any workflow-heavy professional category. Your legal team's software, your finance team's reporting stack, your ops tooling. The "it's already crowded" argument just got significantly weaker.

**A one-line instruction that makes AI code reviews actually useful**

Peter Steinberger added a single instruction to his team's shared AGENTS.md file: every pull request that changes UI state must include an uploaded video. That's it. Now the AI agent documents its own visual changes automatically as part of the review process.

Why it matters: Most AI coding workflows still produce diffs that humans have to mentally simulate. A video of what actually changed on screen cuts review time and catches regressions that line-by-line code review misses entirely. If your team has an AGENTS.md or similar shared context file, this is worth stealing directly.
