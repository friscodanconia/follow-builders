**OpenAI's GPT-6.1 Sol is now doing security audits on real codebases**

CodeRabbit, a code review tool used by development teams, is now running GPT-6.1 Sol as a security agent. It investigates vulnerabilities across complex codebases and proposes fixes, not just flags issues. The security agent works alongside developers to review what it finds before anything gets changed.

Why it matters: This is the first time GPT-6.1 Sol has been publicly attached to a production security workflow, and the timing after Levie's multi-day security warning is hard to ignore. If your engineering team already uses CodeRabbit for code review, you now have an AI agent doing security triage in the same tool. The question is whether "proposes fixes" means good fixes or confident-sounding ones that introduce new problems.

**Box CEO Aaron Levie, four days in, is still sounding the alarm on enterprise security**

Levie endorsed what he called a "good assessment of the on the ground reality for security in most large enterprises right now," adding his now-familiar argument: the fragmented risk surface is getting more complex, not less. Libraries to track, tools to manage, sprawling infrastructure to audit. Most large companies can barely keep up. Most companies outside tech cannot.

Why it matters: Four consecutive days on the same thesis from a CEO who runs software that sits inside corporate security perimeters is not casual commentary. Either Levie is working toward an announcement or he's genuinely alarmed enough to keep saying it until someone listens. Either way, if your company's security audit is still a quarterly spreadsheet exercise, that's the gap he's describing.

**How to clone a video style in minutes using Claude**

Product builder Peter Yang shared a workflow from HyperFrames studio: upload a reference video clip, describe what you want to change, and Claude handles the style transfer. Font, colors, structure all stay consistent with the original. The demo shows the full editing tutorial.

Why it matters: Style cloning for short-form video used to require a motion designer and a few hours. Now it requires a reference clip and a prompt. If you're a creator or a small marketing team producing video content at volume, this is worth a look before you hire.

**Nan Yu flags a split-screen problem nobody fixed on the iPhone Duo**

Builder Nan Yu pointed out that unoptimized apps on the iPhone Duo default to a stretched single-pane layout instead of using the device's split mode properly. The screenshot makes it look as bad as it sounds.

Why it matters: The iPhone Duo has been out long enough that "unoptimized for split mode" should not still be the default experience. Any team shipping a mobile app right now and not testing on dual-screen hardware is leaving a visible quality gap for users who paid a premium for that hardware.
