**"ALG" is the new PLG, and it should make your sales team nervous**

Vercel CEO Guillermo Rauch coined a term worth writing down: ALG, agent-led growth. The argument is that the "product-led growth" playbook (let users try before you sell) is being superseded by agents adopting tools autonomously, before any human ever takes a demo call. If your onboarding requires a human to click through it, you're already behind.

Why it matters: If your startup's go-to-market assumes a human champion inside a customer account, you need a second plan. The procurement decision for a lot of dev tools is about to be made by a code agent evaluating APIs at 2am, not a VP of Engineering in a quarterly review.

**The personal agent that doesn't care which model you're using**

Peter Yang, a product leader at Replit, shared his six takeaways from Karan Malhotra, co-founder of Nous Research, on how to actually use Hermes Agent well. The most counterintuitive point: the model underneath barely matters. Because Hermes accumulates memory about you and builds skills around your workflow over time, Malhotra says he barely notices when the underlying model swaps. He also recommends using the /personality command to switch response styles depending on what you need, "teacher" for learning, "concise" for getting answers fast.

Why it matters: Yesterday's digest covered Hermes Curator, the system that cleans up an agent's accumulated memory and skills. Today's piece is the flip side: the memory and skills are so valuable that users stop caring about which frontier model is powering the agent. If that pattern holds broadly, the model makers are building commodity infrastructure for whoever wins the agent layer on top.
