**AI Builders Digest — June 7, 2026**

The agent economy is getting its infrastructure. From skill registries that work like npm to doubled usage limits for big refactoring projects, the tools for building with AI are maturing fast.

**Vercel CEO launches Skills API as "npm for agent capabilities"**
Guillermo Rauch announced the Skills API, positioning it as an open registry where developers can share and discover capabilities for AI agents. Think of it like npm but for agent skills instead of JavaScript packages. The service is free and designed to make agents more extensible across platforms.
Why it matters: Right now, every AI agent is an island. If this becomes the standard way to share agent capabilities, your customer service bot could tap into the same skills as your coding assistant. That's how you get from demos to actual productivity.

**Anthropic doubles Claude Cowork usage limits for big projects**
Boris Cherny from Anthropic announced they've doubled the usage limits for Claude Cowork for the next month. The increase applies to the existing 5-hour rate limits, specifically targeting developers who have been saving up large, complex projects.
Why it matters: Anthropic is betting that letting developers tackle bigger refactoring projects will create stickier usage patterns. If your team successfully uses Claude to clean up that legacy codebase you've been avoiding, you'll keep paying for the capability.
https://x.com/bcherny/status/2063028954546733462

**OpenAI showcases Endava's AI-native software delivery**
OpenAI published a case study on how Endava, a global software services company, is restructuring their entire development process around AI agents, ChatGPT Enterprise, and Codex. The company is building what they call an "AI-native culture" across their enterprise operations.
Why it matters: This is what happens when a 11,000-person consulting firm bets everything on AI-assisted development. If it works, every other services company will copy the playbook within 18 months.
